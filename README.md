# 🏋️ GYM FREAK – Gym & Fitness Website

## 📌 About the Project
GYM FREAK is a simple and responsive gym and fitness website created using **HTML and CSS**. It provides information about fitness programs, workout plans, membership packages, and contact details.

The website is designed with a modern look to make it easy for users to explore gym services.

## 🎯 Objectives
- To create a simple gym and fitness website.
- To display different fitness programs and workout plans.
- To showcase gym membership packages.
- To provide basic information about the gym.
- To create a user-friendly website using HTML and CSS.

## 🛠️ Technologies Used
- **HTML5** – For website structure.
- **CSS3** – For styling, layout, and responsiveness.

**Note:** This project does not use JavaScript.

## ✨ Features
- Gym FREAK heading and navigation bar.
- Home section with a welcome message.
- Fitness program cards.
- Weekly workout plan.
- Membership plans with prices.
- About Us section.
- Contact Us section.
- Search bar design.
- Responsive layout for different screen sizes.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension in VS Code.

## 🌐 Deployment
The website can be deployed using **Vercel** by importing the GitHub repository.
